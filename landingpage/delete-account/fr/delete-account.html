Supprimer vos données RadRecon

RadRecon est développé par Dr. Petrányi János Tamás. L’application n’a ni compte utilisateur, ni inscription, ni service cloud. Toutes les données que vous saisissez sont stockées localement sur votre propre appareil : il n’existe donc aucun compte à supprimer sur un serveur. Cette page explique comment supprimer vos données.

Supprimer dans l’application

  • Relevés, points de mesure : ouvrez la liste des relevés ou des points et supprimez les entrées dont vous n’avez plus besoin.
  • Instruments, sources et personnes : ouvrez la liste correspondante depuis l’écran principal et supprimez les entrées.

Tout supprimer en désinstallant

Sur Android et iPhone, la désinstallation de RadRecon supprime la base de données et les fichiers stockés par l’application sur l’appareil. Sous Windows, macOS et Linux, le dossier de données de l’application peut subsister après la désinstallation : supprimez d’abord les entrées dans l’application ou demandez-nous de l’aide. La suppression est irréversible ; exportez donc au préalable ce que vous souhaitez conserver (procès-verbal Word, JSON ou CSV).

Fichiers hors de l’application

  • Les procès-verbaux, fichiers JSON et CSV exportés ou partagés avec d’autres applications sont des copies extérieures à RadRecon. Supprimez-les dans l’application ou à l’endroit où vous les avez enregistrés ou envoyés.
  • Si les sauvegardes de l’appareil sont activées dans les réglages de votre téléphone ou ordinateur, les données de l’application peuvent aussi figurer dans ces sauvegardes. Vous pouvez supprimer la sauvegarde dans les réglages du service de sauvegarde.

Correspondance avec nous

Si vous nous avez écrit par e-mail, vous pouvez demander la suppression de cette correspondance. Envoyez une demande à info@radrecon.hu avec l’objet « Demande de suppression de données ». Nous accusons réception sous 5 jours ouvrés et effectuons la suppression sous 30 jours.
