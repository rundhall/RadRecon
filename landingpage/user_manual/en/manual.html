1. Introduction

RadRecon records field radiation surveys. Each measurement point carries its GPS position, time, instrument, value and unit, and optionally a photo and a note. The points of a survey are shown on a map and can be exported as a Word or PDF protocol, as JSON or as CSV.

The App runs on Android, iPhone, Windows and macOS, in Hungarian, English, German, Spanish, French and Italian. All data is stored on the device. There is no account and no registration. An internet connection is needed only for the map background and, if you use them, for instruments on the network.

2. Main screen and settings

The main screen lists your surveys, with the newest first. Use the New survey button to add one. The top bar gives access to the instruments, the radiation sources, the persons and the settings. The lists of instruments, sources and persons have a search field.

Settings

  • Language: Hungarian, English, German, Spanish, French or Italian, or the phone language.
  • Appearance: light, dark or system theme.
  • Alert thresholds: a limit for each measurement type. When a recorded value reaches or exceeds it, the App warns you with a sound and a pop-up. Leave a field empty for no alert on that type.
  • Expiry notifications: off by default. When switched on, the App reminds you at 8:00 about upcoming expiry dates of sources (service life, inspection) and persons (medical exam, training). Choose how far ahead: on the day, 1 day, 2 days or 1 week before. Notifications must be allowed in the phone settings.
  • Switch company: opens the company switcher, see section 7.
  • Save database to file / Load database from file: saves all data (surveys, points, instruments, sources, persons, marked map areas, photos and attached files) to one backup file, or loads such a file, for example on a new phone. Loading overwrites all data currently on the device.
  • Clear database: permanently deletes all surveys, points, instruments, sources, persons and photos from the device. Make a backup first.
  • Contributors: thanks to the volunteers and organizations that help build RadRecon, and how to join them.
  • Units: the default unit of dose rate (nSv/h, µSv/h, mSv/h, Sv/h, µR/h, mR/h, R/h, µrem/h, mrem/h, rem/h), activity (Bq, kBq, MBq, GBq, TBq, µCi, mCi, Ci) and distance (m, cm, inch, feet). New measurements start with these units. While recording, another unit can be chosen from a list and the typed number is converted automatically. The dose rate alert threshold is converted too, and the protocol uses the selected units.
  • Display units: the unit of personal dose (automatic: µSv, switching to mSv above 1 mSv; or a fixed unit), surface contamination, temperature, pressure and wind speed. The screens and the protocol use these units. The stored values do not change, and the CSV and JSON exports and the backup file keep the stored units. The alert threshold for surface contamination is entered in Bq/cm².
  • Regulatory profile: International (IAEA) or Hungary (OAH). The Hungarian profile adds the Hungarian categories to the classification of sources, see section 4.

Company documents and permits

Every company has documents and permits that carry an identifier and an expiry date, for example the workplace radiation protection rules, the radiation protection description, the physical protection plan or the accident response plan. Open them with the document icon in the top bar of the main survey screen and press New document. Enter the Document name, the Identifier (file / permit number), the Issuer / authority, the issue date, Valid / review due until and a note, and attach any number of files with Attach file. You can add as many documents as you need.

The expiry dates of the company documents and of the certificates of persons are part of the expiry notifications. The documents and their files are included in the backup file and in the company switcher.

3. Instruments

Add your instruments once and select them when you record points. Open the instruments list and press New instrument.

  • Instrument name / type (required), serial number, last calibration date and calibration factor.
  • Reachable over WiFi Modbus/TCP: switch on and enter the IP address or host, port (for example 502), Modbus unit ID (slave address) and register address (the starting holding register of the measured value, float32).

Deleting an instrument keeps past measurements; only the instrument reference is removed from them. The list menu can import and export the instruments as CSV.

Verification and calibration records

Every instrument has a history of verification and calibration records. In the instrument screen, in the Verification and calibration section, press Add record and enter the type (Verification or Calibration), the Date performed, Valid until, the Certificate number, Performed by (lab / authority), and attach the certificate with Attach certificate. The status of the instrument is Valid, Expires soon, EXPIRED or No data.

When you record a point, a warning appears if the selected instrument has an expired or soon expiring verification/calibration, or none at all, and saving a point made with an expired instrument asks for confirmation. The protocol and the CSV show the record that was valid at the time of the measurement and flag an expired one.

Quantity and unit of a Modbus instrument

For a Modbus instrument also set what the register contains (for example dose rate, surface contamination or count rate) and in which unit the instrument returns it (for example nSv/h). The App converts the value into the default unit when it reads it, and automatic logging records the quantity configured for the instrument.

4. Radiation sources

The sources are kept in a registry, opened from the main screen, entered once and attached to measurement points when needed. A source has:

  • a unique identifier and the nuclide (from the list or entered manually);
  • activity at manufacture (MBq) and the activity error (±%);
  • manufacture date, service life expiry and next inspection date.

For known nuclides the App stores the half-life and gamma constant and calculates the current activity. For an unknown nuclide the data can be saved, but the comparison is skipped. The list menu can import and export the sources as CSV.

Source certificate

In the source screen, use Attach certificate to attach the certificate of the source (any number of files). It is included in the backup file.

Classification (D, R, exemption)

Press the classification icon in the top bar of the sources list. For every source the App calculates, from the current activity corrected for decay (from the manufacture activity if the half-life is unknown, flagged on the screen):

  • the D value (IAEA) and R = A/D, and from R the physical protection category 1 to 5 (R ≥ 1000: 1; 1000 > R ≥ 10: 2; 10 > R ≥ 1: 3; 1 > R ≥ 0.01: 4; R < 0.01: 5);
  • the exemption values (exempt activity, specific and general exemption concentration) and whether the activity is at or below the exempt activity;
  • the ADR transport values A1, A2, the ratios A/A1 and A/A2, and the exempt consignment limit.

The checkbox of each source selects it for the total: the sum of R of the selected sources gives the category of sources kept in the same physical protection zone.

With the Hungary (OAH) regulatory profile the screen also shows the radiation protection category I, II or III (decree 2/2022 OAH, section 25), the physical protection level B, C or D (Government decree 190/2011), and the MSZ 62-7 laboratory class from the AM value (industrial A, B, C; medical I to III) with the permitted operation types. Two switches, Regular work with unsealed sources and Use outside the radiation workplace, change the category.

The classification is indicative. Exceptions (for example portable devices) are not handled, the concentration condition of an exemption needs the mass of the material, and the official classification is decided by the applicable law and the regulator.

5. Persons

The persons registry holds the staff taking part in surveys: name, medical exam expiry and training expiry. Inside a survey, open the persons icon and use Assign person to add them to that survey. Removing a person from a survey keeps the person in the registry. Deleting a person from the registry also removes them from every survey. The list menu can import and export the persons as CSV.

Besides the name, the medical exam and the training expiry, a person has a Phone number, several Email addresses and any number of Certificates. Press Add certificate and enter the name (for example radiation protection exam), the certificate number, the issuer, the issue date, the validity and attach the file. The expiry of a certificate can be reminded like the other expiry dates. The phone number and the email addresses are part of the persons CSV, the certificates are not.

6. Doses

RadRecon can keep the dose of each person. Doses are stored in µSv. The persons list shows the annual dose of each person, split by source, and has a Year selector.

  • Online (from detector): during automatic logging from a Modbus-connected instrument the App integrates the measured dose rate over time. When logging stops, the dose is saved for the persons assigned to the survey. This works only with dose rate measurements, and the App tells you if there were longer data gaps. If no person is assigned to the survey, the dose is not saved.
  • Manual: inside a survey open the persons icon and tap a person to enter or correct the online and manual dose for that survey.
  • Passive dosimetry: results of a monthly or bimonthly evaluation, not tied to any survey. In the persons list press Manage doses at the person, then Add passive dosimetry, and enter the dose with Evaluation period start and Evaluation period end. The dose counts for the year in which the period ends.

When you close a survey, Review doses lets you correct the dose of every participant before closing. The dose screen of a person lists all entries of the year with their total, and each entry can be edited or deleted. Use Import doses (CSV) and Export doses (CSV) in the persons list menu to move doses in and out.

Annual dose limit check

The header of the persons list shows the annual limit of the category selected there: Occupational (20 mSv per year) or Public (1 mSv per year). For the selected year, each person’s row shows the dose as a share of this limit, with one of three statuses: within limit, warning level reached (from 50 %) or limit exceeded (from 100 %). Both regulatory profiles use the same limits; the profile changes only the cited source (OAH decree 2/2022 or IAEA GSR Part 3). The check covers a single year: the five-year averaging of the IAEA is not applied, and the category applies to the whole list, not to individual persons. It does not replace the official assessment.

The dose figures help your record keeping and do not replace official personal dosimetry. Check them against the results of your approved dosimetry service.

7. Switching between companies

If you work for more than one company, you can keep the data of each company apart. Open the settings and press Switch company. The screen shows the Active company and the list of saved companies.

  • Switch: select a company from the list and confirm. The current data is saved automatically under the active company before the other one is loaded, so nothing is lost.
  • New company: creates an empty company with the name you enter.
  • Add company from backup file: adds a company from a backup file, for example when you move to a new phone.
  • Deleting the backup of a company removes it from the folder. The data currently loaded is not affected.
  • Choose folder: by default the companies are kept in a private folder of the App that other apps cannot reach. Choose a folder such as Downloads or a cloud drive to reach the backups from your file manager, and undo it with Back to default folder.

Each company is stored as one backup file with its database and photos.

8. Starting a survey

  1. On the main screen press New survey.
  2. Enter the name and, optionally, the location. If you leave the name empty, the App proposes “Survey – date”.
  3. Press Start. The survey opens with an empty point list.

Use the edit icon to change the name and location later, and assign the personnel who take part.

9. Recording a measurement point

Press New point in the survey.

  • Measurement type: dose rate, surface contamination, count rate (cps), neutron count rate (cps) or sampling. Sampling also includes the Meteorology and Gas measurement types, which have no measured value: the weather data or the gas concentrations are entered with the point.
  • Location name, measured value and unit. Each type has a default unit.
  • Distance from source and nuclide, which give a quick estimate of the activity from the measured value.
  • Instrument: select one from your list, or add a new one with the plus button. For a Modbus instrument use the Modbus query button to read the value directly.
  • Position: latitude and longitude, with Live GPS to take the current position or On the map to pick it on the map.
  • This is the source position (max value): marks the point of the highest reading.
  • A physical sample was taken here: enter container ID, amount and sampling method.
  • Notes and a photo taken with the camera or chosen from the gallery.

If the value reaches or exceeds the threshold for its type, the App shows the alert. Every later change to a point is written to its change history, so the original value remains traceable.

Units, error and averaging

Next to the measured value a list lets you choose another unit; the number is converted automatically. Under the value, the Error (±) field holds the uncertainty of the reading in the same unit. Type it by hand when you enter the value manually. The protocol shows the value as “value ± error”, and the CSV has separate columns for it.

With a Modbus instrument, press Averaging measurement instead of a single query. Choose the duration (10 s to 5 min); the App reads the instrument every second and shows the running mean with its error. Done accepts the samples collected so far, Cancel discards them. The value is the mean, the error is the standard error of the mean (1σ, the standard deviation divided by √n), and the number of samples and the duration are saved with the point and printed in the protocol. At least 2 valid samples are needed for the error. The error is statistical: it does not contain the calibration uncertainty of the instrument, and it is too small if the instrument itself smooths its readings.

Nuclide identification and shielding

The Nuclide identification section records whether the nuclide is identified (from the list or other), unknown, or a mixture of sources. The activity estimate from the measured value appears only when exactly one nuclide is identified and the distance from the source is entered. It shows the activity (unshielded).

If the source is behind shielding, press Add layer and choose the material (lead, steel, concrete, tungsten, aluminium or water) and the thickness. Several layers can be added. The App then also estimates the activity of the shielded source. The estimate uses indicative half-value layers and ignores scattered radiation, so it tends to overestimate the activity.

Averaged GPS position

If the GPS accuracy is poor (for example ±10 m), stand still at the point and press Averaged GPS under the position. Choose 30, 60 or 120 seconds. The App collects the positions, weights them by their accuracy, drops the outliers and enters the mean position with an estimated accuracy. An open sky gives the best result. A longer time helps, but the GPS error is correlated in time, so do not expect the accuracy to improve with the square root of the number of samples.

10. Sources at a point

In the point screen choose Manage radioactive source(s) and attach sources from the registry. For each one enter its distance from the measurement point. The App then shows:

  • the current activity, corrected for decay up to the measurement date;
  • the calculated dose rate of each source and the total of all sources;
  • the measured dose rate at the point and the difference (measured minus calculated).

Sources with an unknown nuclide are left out of the total, and an expired service life is flagged with a warning. If the measurement unit cannot be converted automatically, no comparison is made. Detaching a source removes only the link, not the source from the registry.

11. Map

The map shows all points of the survey. Use the camera icon to save a screenshot of the map; it is attached when you export the protocol. From the point list, Save list screenshot does the same for the list. The map background needs an internet connection.

Marked areas

Areas let you mark a part of the surveyed site on the map, for example a surveyed, restricted or contaminated area. Press Mark area on the map. Enter a Name (for example Surveyed area), choose the Shape (Polygon or Circle) and a Colour, then press Draw. For a polygon, tap the corners in turn and press Done; at least 3 corners are needed, and Undo removes the last corner. For a circle, tap the centre and then a point on the edge to set the radius. Areas are drawn with a semi-transparent fill in their colour. The Marked areas button lists the areas of the survey; the list lets you delete an area after confirmation. The areas are included in the Word and PDF protocols (name, shape, geometry and area in m²) and in the backup file.

12. Tools

The tools are in the survey menu (three dots).

  • Automatic logging: records points from a Modbus/TCP instrument by time interval (at least 1 second) or distance interval (at least 1 metre). It shows the points recorded, the last value and failed readings. Logging works only while this screen is open; if the phone locks or you switch apps, it pauses and you have to restart it.
  • Distance measurement: distance and bearing from your current position or a chosen starting point to a target point. With Live tracking the values update as you walk, in the direction of the arrow.
  • Isotope calculator: converts activity (MBq) to dose rate (µSv/h) at a distance, or a measured dose rate back to activity. Built-in nuclides: Co-60, Cs-137, Ir-192, Ra-226, I-131, Na-22 and Am-241.
  • Decay calculator: works in two modes, Activity after time t and Time to target activity. It uses the half-life of a nuclide (from the list, or a custom half-life). With a distance entered, it also shows the dose rate at that distance. The calculation is pure exponential decay: daughter nuclides and other radiation are not included.
  • Unit converter: converts values between the units used in the App: dose, dose rate, activity, activity concentration, surface contamination, count rate, length, area, volume, mass, temperature, pressure, speed, time, irradiance, precipitation rate, aerosol mass concentration and gas concentration. Tap a row to convert the value to that unit; it then becomes the source unit. To convert between the mass and the volume concentration of a gas, the molar mass is needed. Choose the gas from the list to fill it in: 22 gases are listed, while VOC and NOx have no molar mass and it must be entered by hand. The conversion assumes 25 °C and 1 atm. The %LEL unit cannot be converted, because it depends on the limit of the gas.
  • Source search: estimates the direction in which the selected measurement type increases, from the points already recorded in the survey. With fewer than 4 points the estimate is flagged as unreliable. Take more points at different spots in the search area.

The automatic logging screen draws a time chart of the readings while it runs, with the alert threshold as a red dashed line, so you can see the change of the measured value. The chart keeps the last 2 hours at one-second sampling and is not saved. The isotope calculator can use the same shielding layers and then shows the unshielded and the shielded result.

13. Closing, exporting and importing

  • Close survey: the protocol then shows the date as the end time. Points are not locked, so you can still edit them.
  • Export protocol: creates a Word or a PDF protocol, as you choose in the dialog. It contains the point list, the marked areas, the meteorology and gas tables and the attached photos. The Word protocol is delivered as a ZIP file that contains the document and a folder with the photos.
  • Export points (data, JSON): a data file that another RadRecon installation can import.
  • Export points (table, CSV): a table for Excel with position, accuracy, instrument, timestamp, sampling, notes, estimated activity, attached sources and calculated dose rate.
  • Import points (JSON): loads points from a JSON file. Missing instruments and sources are created, and points without a valid GPS position or with an unknown measurement type are skipped with a warning.

When you import a CSV into the instruments, sources or persons list, choose what happens to a matching record: replace it, skip it, or import it as a duplicate.

The protocol uses the units selected in the settings. The CSV and JSON exports keep the stored units. The protocol shows the value with its error and the number of samples of an averaged measurement, and the instrument with its verification/calibration records. The CSV has the additional columns Error (±), Averaging (samples; s) and Instrument verification/calibration; the JSON file carries the same data.

14. Troubleshooting

  • No GPS position: check that location services are on and that RadRecon may use the location, then press Refresh GPS. Indoors the accuracy can be poor; the accuracy radius is stored with the point.
  • Modbus query fails: check that the phone and the instrument are on the same WiFi network and that the IP address, port, unit ID and register address are correct.
  • No map background: the map tiles need an internet connection.
  • No expiry notifications: switch them on in the settings and allow notifications for RadRecon in the phone settings.
  • Poor GPS accuracy: use Averaged GPS in the point screen while standing still, see section 9.

If a problem remains, write to info@radrecon.hu.

15. Important notice

RadRecon is a documentation and calculation aid, not a measuring instrument. Calculated values and the source search direction are for reference only. Verify them against an authoritative source for official records, and follow the instructions of your radiation protection officer. See the Terms and Conditions.
